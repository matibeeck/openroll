| 2026-11-17 | Hand split: notes within ±5 semitones of the split pitch follow the hand whose most recent note (ended < 1 s ago) is closest in pitch; within a chord a right-hand tone is never below a left-hand tone | Keeps a melody that dips under C4 in the right hand without a model; simple and deterministic | Pure split (breaks melodies at C4); DP/HMM hand separation (phase 2 if needed) |

| 2026-11-17 | Basic Pitch runs in a fresh Web Worker per conversion, WebGL backend (OffscreenCanvas) with CPU fallback; cancel = cooperative flag checked between 2 s windows + `worker.terminate()` | UI never blocks; terminate frees all GPU/CPU memory even mid-window | WASM backend (extra .wasm files to ship, not needed yet); a long-lived worker (keeps ~50 MB of tensors alive) |
| 2026-11-17 | Keep Basic Pitch's own note decoder at its defaults (onset 0.5, frame 0.3, melodia on) and clean up afterwards with onset-aware rules: merge same-pitch fragments that have no strong onset (< 0.8) and start ≤ 50 ms after the previous note; drop overtone ghosts (+12/+19/+24 st over a louder sounding note, onset < 0.85, amplitude < 60 %); drop events with onset < 0.6; min length 50 ms | Raw Basic Pitch on synthetic two-hand piano had 76–79 % precision (fragments of sustained notes and overtone ghosts).
