# Salamander Grand Piano samples

Subset (every minor third, A0–C8) of the Salamander Grand Piano V3 by Alexander Holm,
licensed under Creative Commons Attribution 3.0 (CC-BY 3.0): https://creativecommons.org/licenses/by/3.0/

Original: https://archive.org/details/SalamanderGrandPianoV3 — MP3 conversions as distributed with Tone.js examples.
Served locally; the app never fetches them from a CDN.
